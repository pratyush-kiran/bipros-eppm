# Daily Business Sheet (DBS) — Overview

## What is a DBS?
The Daily Business Sheet is the daily cost-and-progress P&L for a construction project.
Every day, supervisors log work done; the system rolls it up four levels:

  Supervisor → Engineer → Site Manager → Construction Manager → Project Manager

For each level you can see, for any date or period (day / week / month):
- **Cost** consumed (Manpower, Admin, Machinery, Fuel, Material, BOQ)
- **Income** earned (BOQ achieved × unit rate)
- **Contribution %** = (Income − Cost) / Income × 100
- **% Achieved vs Plan** = BOQ achieved-to-date / BOQ planned-to-date × 100
- **Cost incl Prelims** = Direct cost + Preliminaries

## Where to find it
Navigate: Projects → <your project> → **Daily Business Sheet** in the left rail.

## The five tabs
1. **Supervisor** — what one supervisor logged today.
2. **Engineer** — rolled up from all supervisors reporting to one engineer.
3. **Site Manager** — (when used) rolled up from engineers.
4. **Construction Manager** — rolled up from site managers / engineers.
5. **PM** — whole-project totals across all CMs.

## Exports
Excel and PDF buttons on the PM tab produce the entire workbook (matching the
"Supervisor-Engineer-CM-PM DBS" template), including the Equipment Register
and Cumulative Days sheets.
